RolRellenator
Creador de personajes basado en el juego de rol
Vampiro: La Mascarada (Edicion 20.º Aniversario).

RolRellenator es una aplicación web desarrollada como proyecto personal que guía al jugador durante todo el proceso de creación de un personaje.

El asistente valida automáticamente las reglas del juego y proporciona información contextual sobre cada decisión para convertir la creación del personaje 
en una experiencia similar a la del propio manual.
Despues las almacena y permite visualizarlas en cualquier momento.

Tecnologías utilizadas
• PHP 8
• Symfony 6
• Twig
• Doctrine ORM
• Tailwind CSS
• MySQL
• JavaScript
